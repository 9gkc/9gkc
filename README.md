### About

I design and build practical security tools, secure applications, and educational platforms with a strong emphasis on **clarity**, **responsible use**, and **long-term maintainability**.

My work sits at the intersection of:

- Application Security & Defensive Tooling
- Full-stack engineering
- Arabic-first technical education
- Open-source projects that remain useful after the first release

> **Responsible-use boundary**  
> Security research and testing are performed only with explicit authorization, within an approved scope, and with safeguards that reduce unnecessary impact.
